# Duncan et al. (2019) — HTML presentation

10 основных слайдов и необязательный пример 3a. Содержание и научные проверки принадлежат этому проекту; общий viewer подключается из приватного werserk/werserk-presentation.

```sh
npm ci
npm run dev
```

Node 22+, npm, Python 3 и beautifulsoup4 (`python3 -m pip install -r requirements.txt`). Для браузерных проверок и PDF — Chromium; CHROMIUM_PATH задаёт путь. Git нужен для получения приватной закреплённой зависимости и проверки исторического источника.

- npm run build — Decimal-подготовка и сборка dist.
- npm run check — полный основной маршрут с заблокированной внешней сетью плюс сохранность научного текста/чисел.
- npm run export — полный PDF, включая 3a; шаги не создают лишних страниц.
- npm run pack — переносимый tar.gz, запуск распакованного пакета: node serve.mjs.

Откройте URL из dev, нажмите «Спикер». Audience и speaker должны иметь одинаковую session. Для проектора — расширенный рабочий стол. Стрелки/Space раскрывают шаги, отдельные кнопки переключают целые слайды; пример возвращает к прежнему шагу родителя.

Редактируются work/slides/slides.html, slides.css, оба JSON в work и научные записи docs. dist/.generated — результаты. Старые outputs — исторический viewer; work/build-slides.py сохраняет его воспроизводимость и не является активной командой npm build.
