# Duncan et al. (2019): полигенные оценки в разных популяциях

Готовая Reveal.js-презентация: **21 основной слайд** и пять необязательных примеров (3a, 12a, 12b, 15a, 17a). Элементы раскрываются по шагам; отдельное окно спикера показывает текущую речь, следующий слайд, указку и таймер. Основной счётчик не включает примеры. Полное чтение и PDF содержат все 26 страниц.

## Быстрый запуск на ноутбуке — готовая сборка

Нужны **Node.js 22 или новее**, браузер Chrome/Chromium/Firefox и `tar`. npm, Python и интернет для самого показа не требуются.

1. Скачайте репозиторий: **Code → Download ZIP**, распакуйте его. Либо используйте обычный `git clone https://github.com/werserk/duncan-2019-presentation.git` с вашим доступом к приватному GitHub.
2. В терминале перейдите в распакованную папку репозитория. Проверьте `node --version`.
3. Запустите:

```sh
bash delivery/start.sh
```

Откройте адрес, который напечатает терминал: `http://127.0.0.1:4173`. Кнопка **«Спикер»** находится на нижней панели, которая появляется при наведении мыши вниз. Оставьте терминал работающим; остановка — **Ctrl+C**. Если порт занят: `bash delivery/start.sh 4178`.

Архив также можно распаковать вручную в отдельную папку:

```sh
mkdir -p ~/Downloads/duncan-2019-show
 tar -xzf delivery/presentation-offline.tar.gz -C ~/Downloads/duncan-2019-show
cd ~/Downloads/duncan-2019-show
node serve.mjs 4173
```

**Не открывайте index.html через file://**: показу и синхронизации нужен локальный HTTP-сервер.

## Аудитория и спикер

Подключите проектор/второй экран в режиме **расширенного рабочего стола**. Окно показа переместите на экран аудитории; окно спикера оставьте на ноутбуке. Оба окна открывайте в одном браузере и профиле, с одинаковым `session` в URL. После открытия окно спикера должно показать «Связь с показом установлена». Полный экран — кнопка в показе или F11.

- **→ / Space** — следующий шаг раскрытия, затем следующий основной слайд. **←** — предыдущий шаг.
- **«Следующий слайд» / «Предыдущий слайд»** в консоли — переход целиком; слайд начинается с шага 0.
- Ссылки **«Пример…»** открывают необязательную ветку. **«Вернуться»** восстанавливает прежний шаг родителя; **«Продолжить»** идёт дальше по основному докладу.
- **«Весь Fig.…»** открывает оригинальный рисунок. Пока он открыт, шаги заблокированы. **Escape** закрывает его.
- **Указка** включается в консоли; движение по текущему превью показывается аудитории. Таймер запускается отдельно кнопкой.
- **«Новый показ»** в окне аудитории начинает отдельную сессию. Не смешивайте ссылки старого и нового показа.

Для чтения: `/reader.html`; полная речь: `/speaker-notes.md`; готовый PDF: `/presentation.pdf`. PDF раскрывает все элементы и содержит необязательные примеры; заметки в нём не занимают отдельные страницы.

## Установка исходников и пересборка

Нужны Node.js 22+, npm, Python 3 с модулем venv. Toolkit уже закреплён локальным tarball и SHA-512 в lockfile: настройка `gh auth` или отдельный Git-доступ для npm-зависимости **не нужны**. Первая установка npm/Python-зависимостей использует интернет.

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
npm ci
npm run build
npm run dev
```

Откройте URL из терминала. После правок выполняйте `npm run build`; перезагрузите оба окна. При изменении содержимого сборка получает новый идентификатор, поэтому старая сессия не переносит шаги в новый текст.

На Arch Linux необходимые системные пакеты при их отсутствии: `sudo pacman -S nodejs npm python`. На Debian/Ubuntu Python venv устанавливается пакетом `python3-venv`; Node устанавливайте в версии 22+. Изменения системных пакетов выполняет владелец ноутбука.

## Проверка, PDF и автономный пакет

Для браузерной проверки и нового PDF нужен Chromium. Системный Chrome можно указать явно:

```sh
CHROMIUM_PATH=/usr/bin/google-chrome-stable npm run check
CHROMIUM_PATH=/usr/bin/google-chrome-stable npm run export
npm run pack
npm run deliver
```

Если системного браузера нет:

```sh
npx playwright install chromium
CHROMIUM_PATH="$(node --input-type=module -e 'import {chromium} from "playwright"; console.log(chromium.executablePath())')" npm run check
CHROMIUM_PATH="$(node --input-type=module -e 'import {chromium} from "playwright"; console.log(chromium.executablePath())')" npm run export
npm run pack
npm run deliver
```

`npm run deliver` копирует свежий архив в `delivery/` и записывает SHA-256/идентификатор сборки. Пакуйте **после** build и export, чтобы архив содержал актуальные слайды и PDF. Проверка исторического входного текста: `npm run check:migration` (требуется Git-история).

## Что редактировать

`work/slides/slides.html` — единый источник слайдов и речи. `data-step` задаёт раскрытие; `data-note-step` связывает речь с шагом, `data-reserve` отделяет ответы для обсуждения. `data-row-steps` задаёт шаги строк вычисляемых таблиц. `slides.css` задаёт композицию. Оба JSON в `work/` содержат научные и условные числовые входы; `work/slide_data.py` — общие точные расчёты для обеих сборок.

`dist/` и `.generated/` — результаты сборки. `delivery/` — закреплённый пакет для показа. Прежние `outputs/` и legacy viewer сохраняются как исторический экспорт, не являются активным Reveal-показом. Общий toolkit хранится отдельно в `werserk/werserk-presentation`; этот репозиторий содержит реальный доклад.
