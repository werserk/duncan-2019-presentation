# Термины презентации

Решения пользователя, 2026-10-08: всегда «полигенная оценка», основной термин для predictive performance — «качество предсказания».

| Понятие | Используемая формулировка |
|---|---|
| PGS, polygenic score | Полигенная оценка; конкретное число — значение полигенной оценки. |
| PRS, polygenic risk score | Термин оригинального названия статьи. PGS в докладе охватывает заболевания и количественные признаки. |
| Выборка / группа происхождения | В конкретном сравнении — выборка; в сводке по AFR/SAS/EAS — группа происхождения. |
| Predictive performance | Качество предсказания; в речи поясняем, насколько хорошо PGS предсказывает признак. |
| GWAS | Исследование ассоциаций по всему геному. |
| SNP | Генетический вариант в одной позиции ДНК. |
| βⱼ | Оценка ассоциации выбранного аллеля с признаком; вес для расчёта PGS. |
| gᵢⱼ | Число копий того же аллеля у человека i; imputed dosage может быть дробным. |
| S | Выбранный набор генетических вариантов. |
| Представленность | Доля публикаций, включающих соответствующую группу; не число участников. |
| Относительное качество предсказания (в данном сравнении) | Отношение одинаковой метрики неевропейской и европейской групп внутри работы × 100%; не общий процент правильных прогнозов. |
| E, Q | Обозначения объяснения: E — исходная метрика внутри сопоставимой пары, Q — относительное значение в процентах (100 × E_non-EUR / E_EUR). |
| p_T | Порог для p-value из GWAS при выборе вариантов для PGS; остальные фильтры применяются отдельно. |
| Linkage disequilibrium, LD | Неслучайная связь между аллелями разных вариантов. |
| LD-r² | Мера LD; порог для clumping, отличается от R² качества предсказания. |
| LD clumping | Выбор индексных SNP по p-value и исключение связанных соседей в заданном окне при выбранном пороге LD. |
| LD reference panel | Генотипы, по которым оценивают LD; отдельная роль от discovery GWAS и target sample. |
| Genetic PCs | Principal components, сводные оси генетических различий между людьми, рассчитанные по многим вариантам. |
| Population stratification / confounding | Структура выборки может смешивать генетические и связанные с группой различия признака/среды; пример с индикатором z иллюстрирует механизм, не вычисляет PCs. |
| Относительная представленность | Доля группы среди публикаций / доля группы в населении мира × 100%. |

В оригинальных рисунках, цитатах и сохранённом тексте статьи английские термины не меняются. Названия ancestry-групп передаются по источнику; азиатские и африканские популяции не объявляются одинаково редкими. Исторические записи и старые утверждённые версии сохраняют прежние формулировки; это история, не действующий глоссарий. Содержание и речь редактируются только в `work/slides/slides.html`.
