В исследованиях PGS преобладают европейские выборки.

Насколько полезны такие оценки для людей другого происхождения?

Полигенная оценкаpolygenic score · PGS

Объединяет информацию о многих генетических вариантах человека в одну числовую оценку. Её используют для предсказания количественного признака или оценки предрасположенности к заболеванию.

Учебный пример · условные данные

Один человек i = 1; три SNP: S = {A, B, C}. Индекс j выбирает строку таблицы.

SNP jВес βjКопии g1jВклад βjg1j
A0,220,4
B0,110,1
C−0,052−0,1

Положительный вес увеличивает сумму;
отрицательный — уменьшает.

Подставляем числа

0,2 × 2 + 0,1 × 1 + (−0,05) × 2
= 0,4 + 0,1 + (−0,1)

PGS1 = 0,4

Условные единицы

Изменим только число копий у SNP B: g1B: 1 → 2. PGS: 0,4 → 0,5.

Дополнительная копия меняет оценку на вес этого аллеля.
